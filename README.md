## 🚀 Featured Projects

**[brain-tumor-detection](https://github.com/mailhashezad/brain-tumor-detection)**
An explainable brain MRI tumor classifier built on a VGG16 transfer-learning model. It uses Grad-CAM to show which regions of a scan influenced a prediction, and includes a local RAG chatbot (Ollama + ChromaDB) that answers questions about the results.
*Python · TensorFlow/Keras · Grad-CAM · RAG*

**[job_matcher](https://github.com/mailhashezad/job_matcher)**
A local AI job-matching system. It takes a resume and finds the most relevant roles from 3,000+ data science job listings using semantic search, and includes a resume chatbot for career guidance.
*Python · NLP · LangChain · ChromaDB · Ollama*
